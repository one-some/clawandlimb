## ClawAndLimb

A sandbox game with destructable terrain and Sims-like building.

Features:
- Infinite world generation based on custom seed
- Multithreaded world generation(*)
- Building!
- Destructable terrain! Try using the shovel to delete huge chunks of terrain, or take a block out of the world with the pickaxe.


(*): At the time of me stopping work on the game, chunk threading was undergoing an overhaul. World generation will be slower than it should be.
